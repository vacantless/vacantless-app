## Sentence rules

- 12 words or fewer per sentence. The gate fails at 14.
- One idea per sentence. Buttons are 1 to 3 words.
- No upper case words. No dashes as punctuation.
- No "&", no "/", no parentheses inside landlord copy.
- Numbers as digits. Money as $29.95.
- Say who does what with "we" and "you".
- Never explain what does not happen. Say what happens.
- French is written, not translated. Every English key has a French sibling.

## The gate

`npm run test:plain-language` runs on every commit script. It fails when any
offender is new, or appears MORE often in a file than the baseline records. When
copy improves it tightens the baseline in place, so the count can only go down
and a phrase you deleted cannot be pasted back for free. It also fails if a file
the baseline covers has been dropped from the gate.

`npm run test:plain-language -- --strict` ignores the baseline and is the
acceptance check for the copy sweep: it goes green when the sweep is finished.
